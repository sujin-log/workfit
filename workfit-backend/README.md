# 청년워크핏 백엔드 (FastAPI)

실제 API 데이터와 생성형 AI를 활용한 근로기준법 RAG 기반 노무상담 플랫폼

---

## 📋 개발 기획

### 핵심 목표
청년들이 직면한 근로 문제에 대해 **신뢰성 높은 AI 상담**을 제공하여 법령 기반의 정확한 정보 습득 지원

### 기획 배경
- 근로기준법은 청년 근로자의 기본 권리를 담고 있으나, 이해도가 낮음
- 기존 상담 서비스는 비용 발생 또는 접근성 제한
- AI만으로는 할루시네이션(거짓 정보) 위험이 높음
- **해결책**: RAG 파이프라인으로 실제 법령 기반의 정확한 AI 상담 제공

### 주요 기능

| 기능 | 설명 |
|------|------|
| **워크챗 (RAG 노무상담)** | 근로기준법 132개 조문 기반 AI 상담 |
| **커뮤니티** | 청년들 간 경험 공유 및 토론 |
| **북마크** | 관심 정책 저장 및 관리 |
| **마이페이지** | 채팅 이력, 북마크, 프로필 관리 |

## 🛠️ 구현 기술

### 백엔드 아키텍처
```
FastAPI (웹 프레임워크)
  ↓
RAG 파이프라인 (워크챗 핵심)
  ├─ 국가법령정보센터 API (데이터 소스)
  ├─ ChromaDB (벡터 데이터베이스)
  ├─ bge-m3 (임베딩 모델)
  └─ Gemini 3.6 Flash (LLM)
  ↓
메모리 저장소 (사용자, 게시글, 북마크)
```

### 기술 스택

**프레임워크 & 서버**
- FastAPI 0.115.0 - 비동기 웹 프레임워크
- Uvicorn 0.30.6 - ASGI 서버

**인증 & 보안**
- JWT (python-jose) - 토큰 기반 인증
- bcrypt - 비밀번호 해싱

**RAG 파이프라인**
- ChromaDB 0.4.24 - 벡터 데이터베이스
- BAAI/bge-m3 - 한국어 최적화 임베딩 모델
- Google Generative AI 0.8.6 - Gemini API 클라이언트
- sentence-transformers - 임베딩 생성

**데이터 & 저장**
- 국가법령정보센터 API - 근로기준법 데이터 소스
- JSON - 더미 데이터 (정책, 뉴스)
- 메모리 저장소 - 사용자/게시글/북마크

## 🎯 워크챗 (RAG 노무상담) 구현

### 동작 원리

**1단계: 데이터 수집**
- 국가법령정보센터 API에서 근로기준법 132개 조문 수집
- 각 조문에 수집일자 메타데이터 기록 (2026-09-12)

**2단계: 임베딩 & 벡터화**
- bge-m3 모델로 각 조문을 의미 벡터로 변환
- ChromaDB에 저장 (1.4MB)

**3단계: 사용자 질문 처리**
```
사용자 질문 입력
    ↓
질문을 bge-m3로 임베딩
    ↓
ChromaDB에서 유사도 기반 Top-5 조문 검색
    ↓
Gemini 3.6 Flash에 [검색된 조문 + 질문] 전달
    ↓
자연스러운 노무상담 답변 생성
    ↓
수집일자 및 법령정보센터 링크 자동 추가
    ↓
최종 답변 반환
```

### 예시

**입력:**
```
질문: "퇴사 후 임금을 안 줬어요. 어떻게 해야 하나요?"
```

**처리:**
```
검색 결과:
  1. 제36조 (금품청산) - 유사도 60.9%
  2. 제37조 (미지급임금 지연이자) - 유사도 59.5%
  3. 제43조 (임금지급) - 유사도 58.1%
  ... (Top-5)
```

**출력:**
```
근로기준법 제36조에 따르면 사장님은 네가 퇴사한 날부터 
14일 이내에 모든 임금을 지급해야 해. 너랑 따로 합의해서 
기일을 연장한 게 아니라면 14일이 넘은 시점부터는 엄연한 
법 위반이야. 일단 사장님한테 법적으로 14일 이내 지급이 
원칙이라고 다시 정중하게 연락해보고, 그래도 안 주면 
고용노동청에 임금체불로 진정을 넣으면 돼.

—
본 답변은 2026-09-12 기준 근로기준법을 근거로 하며, 
최신 정보는 국가법령정보센터(law.go.kr)에서 확인하실 수 있습니다.
```

## ✨ 기대 효과

### 사용자 관점
1. **정확한 정보**: 실제 법령 기반의 신뢰할 수 있는 답변
2. **접근성**: 24/7 언제든지 법률 상담 가능
3. **비용 절감**: 법률 전문가 상담 비용 없음
4. **이해하기 쉬움**: 친근한 톤의 설명

### 기술 관점
1. **할루시네이션 방지**: RAG로 거짓 정보 생성 차단
2. **확장성**: 다른 법령도 쉽게 추가 가능
3. **신뢰성**: 실제 API 데이터만 사용
4. **투명성**: 답변의 법령 근거를 명확히 제시

### 비즈니스 관점
1. **청년 정책 플랫폼의 완성도 향상**
2. **사용자 체류 시간 증가** (AI 상담 활용)
3. **재방문율 증가** (신뢰할 수 있는 정보)
4. **향후 확장 가능** (다른 법령, 다른 도메인)
